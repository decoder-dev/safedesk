Applicazione open source per desktop remoto, l'alternativa open source a TeamViewer.
Codice sorgente: https://github.com/safedesk/safedesk
Documentazione: https://safedesk.com/docs/it/client/android/

Per consentire a un dispositivo remoto di controllare il tuo Android tramite mouse o tocco, devi permettere a SafeDesk di utilizzare il servizio "Accessibilità". SafeDesk utilizza l'API AccessibilityService per implementare il controllo remoto su Android.

Oltre al controllo remoto, puoi anche trasferire facilmente file tra dispositivi Android e PC con SafeDesk.

Hai il controllo totale dei tuoi dati, senza preoccupazioni per la sicurezza. Puoi usare il nostro server rendezvous/relay, optare per l'hosting autonomo, o scrivere il tuo server rendezvous/relay. Il server auto-ospitato è gratuito e open source: https://github.com/safedesk/safedesk-server

Scarica e installa la versione per desktop da: https://safedesk.com — potrai quindi accedere e controllare il tuo computer dal cellulare, o controllare il tuo cellulare dal computer.
